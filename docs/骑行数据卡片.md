# 一、概述

![](img\骑行数据卡片效果图.png)

该卡片控件负责骑行历史数据的可视化展示，支持按周、月、年多维度切换。其核心点有：

- **数据分页**：支持水平滑动，类似`ViewPager`。
- **异步加载：**分页数据按需加载，并具备并发控制和内存缓存。
- **复杂交互**：支持”**滑动翻页**”和“**长按选中**”两种手势，且具备页面切换后y轴平滑伸缩动画。



# 二、实现细节

卡片内部又拆分为多个小组件：

![](img\骑行数据卡片结构示意图.png)

- `RideRangeTabView`：自定义顶部tab控件，切换tab时有选中滑动动画。
- `RideDataChartView`：自定义骑行数据柱状图表控件，支持”滑动翻页”和“长按选中”。页面切换后y轴平滑伸缩动画。
- `RecordAnalysisCard`：卡片控件，负责整合`TabView`和`ChartView`，同时监听`ChartView`长按并展示对应时间区间数据。

## **2.2 RideDataChartView（自定义柱状图表View）**

这是整个模块最复杂的视觉组件，采用纯 Canvas 绘制。

1. **分页与坐标系设计**

- **负坐标系滑动**：为了实现“Page 0 在最右侧，向右滑动查看旧数据”的体验，View 采用了负坐标系。scrollX 的范围是 `[-(pageCount-1) * pageDataWidth, 0]`。
- **按需绘制** (Performance)：在 `onDraw` 中，通过计算 `scrollX` 与 `pageDataWidth` 的比例，仅绘制当前可见的 1~2 页数据，避免了长列表绘制的性能开销。
- **自动对齐** (Snapping)：通过 `OverScroller` 在 `computeScroll` 中实现。当滑动停止时，会自动吸附到最近的页码。

2. **视觉增强**

- **Y轴伸缩动画**：当切换页面或数据状态改变时，Y 轴最大值不直接突变，而是通过 `ValueAnimator` 对 displayMaxAxisY 进行插值，使柱状图高度产生平滑的伸缩效果。
- **局部剪裁** (Clipping)：使用 canvas.clipRect 确保柱状图内容不会溢出到左侧固定的刻度文字区域。
- **交互模式切换**：通过 `handleSelection` 方法处理。在 DOWN 后 200ms 内无位移则视为“选中模式”，此时拦截滑动事件，绘制垂直指示线并触发回调。

3. **UI细节**

- **x轴坐标绘制**：通过`isXAxisEdgeAligned`设置x轴起止刻度（label）对齐方式是靠图表两边绘制，还是与柱状图居中对齐。



## **2.3 AbsChartController（数据中台）**

该抽象类封装了通用的分页加载逻辑，解耦了 View 与 Repository。

- **并发控制**：引入 `Mutex` (协程锁) 和 `loadingKeys` (线程安全 Set)。确保同一页码的数据在同一时间只有一个协程在加载，防止滑动过快导致的重复请求。
- **状态机设计**：利用 RidePageData（Loading, Success, Error）驱动 UI。View 根据不同的状态绘制 Loading 动画、数据柱子或错误占位。
